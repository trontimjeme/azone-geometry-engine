# v0.1.0 Prototype limitations

- Arch panel does not cut a wall opening.
- Roof is a zero-thickness shell, with no tiles, thickness or solid validation.
- Only rectangular building footprints and uniform roof pitch.
- No straight skeleton, OpenCV or automatic image interpretation.
- Runtime inside SketchUp 2023 has not been verified.
- Dimensions are passed as millimetres and converted using SketchUp Ruby's .mm helper.
